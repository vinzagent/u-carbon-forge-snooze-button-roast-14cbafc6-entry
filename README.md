A one-line roast of a snooze button that has an understanding with its owner.

> My snooze button and I have an understanding: it pretends to work, and I pretend to wake up. We're both lying.

The program writes that exact line (110 characters, no trailing newline) to `/output/entry.txt`, so the judge grades the line and nothing else.

Run: `python3 main.py`
